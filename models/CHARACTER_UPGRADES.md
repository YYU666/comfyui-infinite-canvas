# 可选四视图模型升级

此扩展不改变原有 `core-h3` 和 33 文件 `full` 配置，也不覆盖旧模型。精确文件、字节数、SHA256 和来源记录在 [character-upgrades.json](character-upgrades.json)。下载后放在配置的模型根目录对应路径，逐文件校验哈希，再通过实际 `/object_info` 确认加载器可选。

新增画布预设：

| 预设 | 模型和处理 |
| --- | --- |
| `outfit_qwen21_turbo` | Qwen 2.1 Turbo INT8，官方固定 8 步，不调用高清模型 |
| `outfit_qwen21_turbo_7b` | 相同 Turbo 基础采样，各视图分别 SeedVR2 7B INT8 高清 |
| `outfit_muse_v4` | Muse V4.0 INT8 Extended + Identity Edit V2，默认 16 步，无高清 |
| `qwen_turbo_edit` | 独立 Turbo 图像编辑 |
| `image_upscale_7b` | 独立 SeedVR2 7B 高清 |

母图版面必须按用户提供的模板选择或设置，不假设所有人都使用同一种四视图。逐面板处理后按原母图尺寸和坐标回贴；高清提升面板采样细节，最终拼图仍保留模板尺寸。旧节点缺省继续采用原来的模型和低于 1K 才 3B 高清策略。

需要严格保留头像景别时，自定义面板可指定 `editRegion: [x, y, width, height]`（面板内归一化衣物区域）和 `preserveOutsideRegion: true`。流程在采样时使用真实遮罩，并在单图、高清及最终拼图中恢复区域外的母图像素。`garmentPrompt` 可单独描述该头像中可见的衣领或肩带；受保护头像提供此字段后不再接收整身穿搭图，身体面板仍使用完整穿搭参考。区域应依据用户实际模板确定，不能沿用其他人的面板边界。需检查新旧衣料交界处，区域保护本身不保证领口自然。

Muse 文件来自公开镜像，文件 SHA256 与作者发布的精确版本一致；镜像不是作者的原始托管。作者限制和 Krea 基座许可需分别核对，不因下载成功推定允许商用或再分发。模型、人物素材及生成结果均不进入 Git。

默认头像采用固定景别：`presentationCrop: [0, 0, 1, 0.72]` 保留顶部 72%，默认衣物编辑区为底部 28%。因此默认最终头像会裁掉默认衣物编辑区，不展示这一区域的换装结果。需要在头像中展示衣领或肩带时，应根据用户模板显式设置互相重叠的 `presentationCrop` 与 `editRegion`，不要自动扩大编辑区到脸部。区域外母图像素先在原面板坐标中恢复，再执行展示裁剪；旧版像素版面高清则沿用原有 768×1344 母图裁片及独立面板尺寸。

24GB 显存机器仍依赖 ComfyUI 内存管理和分块 VAE，模型可加载不等于任意尺寸都能成功。实际身份一致性、运行耗时和显存使用须通过当前画布真实生成验收。
