# UV结果预览验收（本地，2026-11-04）

原问题：8组UV输出的几何相同，都复用了灰模海报，无法在模型上比较切缝。

当前实现读取成功UV任务登记的真实model.glb，校验SHA256，在有界CPU子进程中生成640×480预览。橙色表示真实UV不连续的边，青色表示几何开放边界；不是三角网格线，也不是自动判定错误。棋盘通过真实UV插值，帮助检查拉伸、方向与密度。固定正面只显示可见表面，背面仍需要后续可旋转检查。

节点支持切缝/棋盘/灰模切换和点击放大；放大弹层挂到页面根部，避免画布缩放影响。通过当前页桥上传预览并绑定处理/结果节点，使用正常保存屏障；模型、UV及原灰模海报不改写。新完成任务可点击“显示UV切缝”。

已核验：8组预览具有8个不同切缝图哈希，16个对应节点保存成功，revision606；71节点、27个3D节点、61连线保留，模型路径和任务身份未变。切换棋盘、放大加载640×480图像、关闭后恢复切缝已在当前页验证。28项Python测试、前端预览辅助函数/迁移/恢复测试及local-tools构建通过。

本次仅修复展示，不代表45岛/58岛方案通过最终UV质量验收；原有局部密度、方向和拉伸问题仍需后续处理。未上传GitHub或发布。

本地证据：`.cache/native3d/uv-visual-preview/verification.json`、`receipts.json`和`review.jpg`。视觉检查采用bounded-model-vision，读取1张1280×480对照图（67892字节），结构基线与45岛方案的切缝差异清晰。
