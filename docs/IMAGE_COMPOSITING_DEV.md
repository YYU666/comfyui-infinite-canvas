# 本地图像调色、混合与 RGBA 通道打包

画布新增三种本地处理节点：照片调色、图像混合、RGBA 通道合并。通过画布的添加菜单创建，连接图片素材或已输出的处理节点。无需提交 ComfyUI 任务。

这三类属于「官方节点」。本机实验快捷工具和用户安装的工作流位于独立的「第三方工具」分组，沿用 [本机工具隔离规则](local-node-tools.md)。普通公开构建不会读取或预装本机工具清单；源码提交和发布包不包含本机清单、私有工作流包、模型或用户素材。

## 照片调色

提供 17 类独立调整：基础、HSL、色阶、曝光度、白平衡、自然饱和度、曲线、阴影/高光、色彩平衡、可选颜色、黑白、照片滤镜、通道混合器、渐变映射、反相、阈值、色调分离。

节点内始终显示按类别分组的 17 项工具按钮，选中项高亮；也可用「调整类型」下拉框切换。已有基础调整参数继续保留。

- 色阶：在直方图下拖动黑场、中间调、白场三角；输出渐变两端控制输出黑白场，支持 RGB 总通道和单独颜色通道、自动色阶及数值输入。
- 曲线：点击添加控制点、拖动调整、双击删除内部点；支持键盘、RGB 与分通道及常用预设。使用 PCHIP 插值，限制段内过冲。
- HSL：全色及红、黄、绿、青、蓝、洋红范围，分色范围柔和过渡。
- 每个节点仅应用当前选中的调整，各类参数独立保存；需要多个调整时串联节点，并逐步输出。重置仅作用于当前调整。

## 图像混合

底图、叠加图及可选遮罩共三个输入。支持 14 种混合模式、混合强度和尺寸适配。遮罩可选亮度、R、G、B、Alpha，支持反相；RGB/亮度遮罩同时乘以透明度。

## RGBA 通道合并与 TGA

分别向 R/G/B/A 端口连接或上传灰度贴图。每个输出通道可选源图片的亮度、R/G/B/A，支持反相和缺图常量；默认 RGB=0、A=255。至少连接一张输入，尺寸取 R→G→B→A 首个已连接贴图，其他输入按最近邻缩放。

预览可选 RGB（忽略透明度以便检查数据）、RGBA、单通道灰度。点击「输出 PNG + TGA」后，可下载原始 32 位 TGA。普通调色及混合节点也提供 TGA 导出入口。

TGA 使用未压缩真彩色 BGRA、左上原点及 8 位 Alpha，从处理后的原始像素编码，保留 Alpha=0 时的 RGB。可见 PNG 预览可能受浏览器预乘影响；通道打包串联优先读取保存的原始 TGA。普通透明 PNG 等图片的 RGB/亮度读取会明确拒绝，请使用不透明灰度源或节点输出的原始 TGA；读取 Alpha 通道允许。

## 保存与限制

输出进入当前项目素材目录，并保存真实结果节点和来源连线。参数或上游变化后，旧处理结果会失效，需重新输出。素材替换、上传、自动保存和导出附件沿用现有 revision 屏障。项目副本通过自身项目 ID 读取素材及 TGA。

处理浏览器解码后的 8bit RGBA/sRGB，不支持 PSD、ICC 工作流或 HDR/16bit，不声明与 Photoshop 私有算法像素等价。完整输出最多 33,554,432 像素，单边最多 16384；大图完整输出仍需相应内存。预览长边最多 512 像素。

## 性能设计

- 预览防抖 140ms，参数变化、移除节点或关闭页面时取消旧任务并释放 Worker、位图及预览 URL。
- 像素运算通过 Worker 执行，输入输出缓冲区使用转移列表。
- RGBA 逐张转移输入到 Worker，每张立即写入最终通道并释放，不同时保留四张完整 RGBA。位图预览先缩小再读像素，TGA 直接解码到预览尺寸；原始 TGA 解码、最近邻缩放及 TGA 编码均在 Worker 内执行。
- 预览的透明度检查基于采样像素；完整输出会使用有界小块扫描原始位图，拒绝被缩放遗漏的透明像素，避免静默丢失通道数据。
- 共享上游的节点快照在单次读取内建立索引及记忆，避免 RGBA 多端口链指数递归；不跨编辑复用缓存。
- 曲线、曝光、白平衡、反相及色调分离使用精确字节查表，保持原有舍入和 Alpha。
- 成功上传后直接使用项目资产 URL，避免创建随后被替换且未释放的 Blob URL。

## 开发与验证

隔离开发可使用 `scripts/start-image-compositing-dev.ps1 -PythonPath <已安装工作台依赖的Python>`，运行时、项目和数据隔离在 `.cache/feature-dev/`。其中 projects 是保存的项目库，不能作为普通缓存清理。开发实例不连接生产 ComfyUI；多端口服务使用独立会话 Cookie。

此开发实例从 `.cache/feature-dev/ui/` 加载前端。配置被 Git 忽略的本机工具清单后运行 `npm run build:canvas-dev`，再启动实例；后续本机更新也使用该命令。公开构建和下面的公开测试仍使用 `dist/`，不会替换开发实例的工具入口。

```text
npm run build
npm run test:node
node test-image-process-ui.mjs
node test-canvas-current-page-ui.mjs
node test-canvas-clipboard-ui.mjs
python -m unittest test_project_store test_workbench_multi_instance test_workbench_security
node scripts/benchmark-image-processing.mjs
```

浏览器测试使用隔离的合成项目，不写入用户项目。像素测试覆盖调色、混合遮罩、曲线与色阶图形交互、原始尺寸输出、保存重开、过期上游拒绝、通道合并、Alpha=0 的原始 RGB、TGA 下载、原始附件串联、替换素材和项目副本。

基准脚本使用固定种子的像素，报告 1MP 调色、4096×4096 合并/导出及共享节点链的耗时和输出 SHA256。可通过 `--baseline <旧版源码模块目录>` 比较并断言字节/签名一致；时间仅为本机测量，不作为 CI 门槛。

本地优化前后对照（Node 24.13.0、Ryzen 9 5950X，预热后 3 次中位数；节点图为 5 次）：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 1024×1024 曝光像素运算 | 207.61ms | 3.10ms |
| 1024×1024 曲线像素运算 | 85.27ms | 3.15ms |
| 4096×4096 曲线像素运算 | 1331.14ms | 53.48ms |
| 9 层、每层四端口共用上游的快照 | 212.56ms | 0.07ms |

所有基准输出 SHA256 一致。像素运算时间不含图片下载、解码、PNG 编码、项目保存或完整用户操作时延；全尺寸大图仍受内存和复杂调整算法成本影响。
