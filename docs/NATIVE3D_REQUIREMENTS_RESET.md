## 1. 本轮决定

用户指出最新UV越做越偏，要求先整理流程和历史要求。本轮停止继续提交减面、AI分区、UV和烘焙试算；只整理文档。不上传、不发布，不删除源资产或历史结果。

最新固定圆形边界UV保留为不满足用户需求的实验对照，不能成为默认工作流，也不能以零重叠或成功保存认定验收。这里的“未通过”是产品/视觉验收结论；后台任务计算成功的事实不改写。

后续实现以用户要求和本清单为约束。算法、阈值、岛数、成功任务ID不是用户需求，不能反过来修改验收目标。旧文档中的“当前”“已交付”“待检查”必须结合本次纠正理解。

## 3. 后续应遵循的制作顺序

1. **导入与资产盘点**：FBX/GLB/OBJ，高模、已有UV、贴图、材质槽、单位/变换；保留源数据。
2. **选择减面路线与逐级LOD**：明确AI候选或原高模保形路线。按已记录比例/预算逐级处理，检查形体、孔洞、部件和偏差；各真实LOD出现在画布。Nanite复用本例LOD0。
3. **原高模分析**：真实AI分块和AO证据；缓存可复用，来源不能换成低模。映射给目标LOD并显示不确定区域。
4. **结构补缝**：AI分区只是起点；补凸转折、凹转折和凹槽开口。AO辅助选择凹处，不追随每个纹理暗点。整合噪声小区域，保留结构理由。
5. **先审切缝**：3D展示分区→凸角→凹处/AO→合并候选；允许先看后确认，当前不支持的编辑能力应明确。
6. **自然展开与必要修正**：沿结构缝展开；局部舒展失败时优先检查开口、拓扑及必要补缝。不能换成圆形/方形边界来假满足“方正”。允许可控拉伸，严重问题定位到局部。
7. **密度、方向与排布**：表面积归一化后，还要看局部棋盘；整合合理朝向，在间距要求下提高实际利用率。三者共同检查，不只追求一个数字。
8. **UV视觉验收**：同模型的最终UV图集、表面棋盘、切缝与异常位置同屏/可切换。确认这是最终排布，不是临时诊断。可审查结果与可生产结果分开。
9. **其他LOD的UV策略**：尽量延续布局与材质；传递失败时有明确重建/对烘策略。尚未验证不能说整套LOD贴图已共用。
10. **4K材质烘焙**：同一正确高模对应到已验收UV的低模；先Normal/AO，再原材质通道。显示漏投、歧义和凹处问题；质量不足可局部修复。
11. **成品与导出**：平滑/切线、材质、不同视角检查，导出FBX等与独立贴图；保存项目、预设和来源。

## 4. 这次具体做偏了什么

| 偏差 | 事实 | 应恢复的约束 |
|---|---|---|
| 为零重叠改成圆边 | harmonic把每岛边界固定为凸圆，最终多个大圆盘 | 边界应服务于模型结构与自然展开；固定凸边界最多是算法内部初值/诊断，不能直接算满足用户要求 |
| 绕过结构切缝 | v3只保留AI大区及必要拓扑边，没有旧凸/凹/AO全部约束 | 恢复AI→角度→凹槽/AO的实质流程，不是仅改模式名称 |
| 把少岛当目标 | 保留57岛，牺牲了局部舒展 | 岛数由结构与结果决定，不硬保57或追求越少越好 |
| 平均密度替代表面一致 | 平均岛密度统一，但局部面积加权密度P95/P05仍3.58 | 看实际棋盘格，说明局部差异；不能用“统一密度”标题掩盖 |
| 朝向要求被放下 | 最新任务实际使用 `alignDirection=none` | 用户没有取消方向整理；应明确局部合理朝向与允许打包旋转的关系 |
| 将容忍拉伸理解过宽 | 54岛有拉伸告警，棋盘明显挤压 | “允许一些拉伸”不是无限失真授权 |
| 把排布成功当排布合适 | 实际面积利用率约61%，圆边留下大量空隙 | 方正服务于利用率，不是硬变形；利用率和失真共同评价 |
| 没直接展示UV | 默认显示切缝，后补独立图集卡片 | 展开完成就直接展示最终UV与棋盘，减少用户反复追问 |
| 规格与试验混在一起 | 文档包含多个“当前”、旧面数/门槛和反复替代路线 | 顶部固定最新要求和状态，历史只作记录，不当默认 |

45°角度、2%支持范围、4%链长、拉伸P95≤2、20次SLIM、57岛、固定圆边均是实现试验设置，不是用户指定的不可变要求。用户明确允许适度拉伸后，旧拉伸硬阈值已不适用；但几何正确、诚实标注和生产质量目标没有撤销。

AI分区边界也是建议来源，不是每条都必须切开的用户指令。是否合并相邻区域，应结合结构、凹槽、展开失真决定，不能把模型标签直接升级为全部硬边界。

## 6. 后续执行纪律

先恢复规格一致性，再进入实现。每个候选必须说明遵循了哪些结构缝、增加/遗漏了什么；不能为了让程序返回成功悄悄切换问题。先做有依据的局部验证，保留同输入同视角对比，再决定是否跑全模型。用户未要求本轮继续试算，因此本文不触发新任务。

验收同时看：来源几何、结构合理性、碎片、局部拉伸与密度、朝向、利用率、重叠/间距，以及画布可见交付。检查通过只是证据，不能代替用户对用途与观感的判断。
