## 1. 四视图的准确含义

本项目需要的是角色身份与身体参考表，不是建模用的前/后/左/右四张全身正交图：

| 位置 | 内容 | 目的 |
| --- | --- | --- |
| 左上 | 正面胸以上近景头像 | 身份母图、五官、妆容、完整发型 |
| 右上 | 同景别约45°头像 | 同一身份的转角与头发结构 |
| 左下 | 无头背面身体、手脚完整 | 背部服装、体型及发长 |
| 右下 | 无头正面身体、手脚完整 | 身体比例与服装基准 |

单格 1152×2048；四格 2304×4096。先逐格生成和确认，再拼接。最终拼接不再次生图、不拉伸人物、不为了凑画幅切掉手脚。

## 4. 建议固定的生产顺序

1. **建立角色配方。** 确认身份参考、目标风格、服装正背面、饰品、发型、身材比例和鞋履。截图缺失的背面/下装属于设计空缺，先形成明确配方，不让模型在每一格分别猜。九头身可作为本项目默认，允许角色覆盖；短裤赤足是当前白发案例要求，不写死给所有人。
2. **确认正面头像。** 已有合格母图直接复用。需要截图写实化时只在这里进行一次，并明确用户接受后的图片才是身份基准。完整发顶，小幅顶部留白，下沿锁骨/上胸；用可视构图框统一头部占比，不机械执行互相冲突的百分比。
3. **由确认头像生成45°。** 保留同一景别、脸大小、发型、妆容、灯光。分开记录转头方向与约45°目标，不能把全侧脸或轻微转头算同一个档位。沿用RGB落盘边界，生成后单独确认。
4. **确认正面身体。** 使用角色配方和可用的身份/服装/比例参考。先保留头到脚完整生成以检查解剖和约定头身比例，再选择无头输出裁切；保留完整原图。裁切应检查颈部、手脚位置并支持调整，不照抄固定坐标。多参考用途要明示，现有一键节点的单参考限制需要改造。
5. **由确认正身生成背身。** 以正面身体锁定身材、尺度、服装与鞋履，再结合真实背部参考（若有）转180°。检查背面不是复制胸前口袋、纽扣、吊坠或前脚；不得独立回原肖像猜出一套新衣服。
6. **逐格验收后拼版。** 四张均保存原图、来源与有效配方。左上正脸/右上45°/左下背身/右下正身，纯拼接输出PNG，并保留单图。当前清晰度足够，不默认SeedVR2或DLSS5；高清属于独立、可撤回的后续步骤。

头像分支和身体分支在各自输入已确认后可以调度；本机GPU按单队列顺序执行，不能为并行抢显存破坏稳定性。

## 5. 批量产品必须具备的操作

每个角色提供四格预览、独立状态、可见输入、真实执行参数，以及「生成本格」「重试本格」「接受本格」「查看原图」「继续下一步」；整图作为最终交付，单格不藏在后台。所有按钮都明确是否立即计算。

重试默认只动本格；改变已确认正面头像时，45°标记为来源过期；改变已确认正面身体时，背身标记为来源过期。已经生成的旧结果保留，拼版只引用同一版本配方中已选定的四张，不悄悄换图。

同配方复现沿用保存的seed；明确“换种子再试”时仅本格换seed并记录。初步建议每格一次正常尝试、最多两次有明确调整理由的返工，之后进入待处理队列，继续其他角色；次数是生产策略草案，不是模型质量保证。

必须显示实际生效的模型、版本/文件标识、提示词模板版本、参考哈希、步骤、参考精度、缓存策略、LoRA、各格seed与裁切区域。扩展的seed等必须绑定到真实采样输入；不要显示不生效的通用控制项。

任务表区分：未连接/待生成/生成中/待检查/已接受/需修改/失败/已取消/来源过期。服务不在线时不要把旧图片或note显示成仍在生成。失败角色不阻塞整批，其已接受阶段保持可恢复。

## 6. 检查要有主次，不能再次过度阻断

文件损坏、错角色/多人、背面仍正面、严重肢体错误、缺脚缺手、明显违反已锁定服装，不能自动成为成品。自动检测只能给出有证据的结论，身份/朝向模型尚未接入，不能冒称已有可靠自动审图。

轻微亮度、发丝、布纹、近似角度误差和构图偏差给对比与警告，可人工接受；不以一个固定相似度分数决定所有人。背部没有原始参考时必须注明设计补全，不能声称客观还原。

九头身在无头成品里无法直接完整量测，应保留头到脚的生成版本、头高定义及裁切记录供检查。大型发髻不能等同于解剖头高。
