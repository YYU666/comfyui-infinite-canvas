# SAM3.1 绿幕白模

本地白模节点对已连接的视频使用 `person`、`pole` 等文字分割，随后以 CPU 合成纯绿背景和白色主体。提供 flat / shaded、maskGrow 和 maskFeather。导出保持输入帧数、尺寸、帧率和音频；每次成功导出创建独立视频素材，旧素材及其下游连接保持原引用。

分割沿用本机 ComfyUI 官方 SAM3 节点与 `sam3.1_multiplex_fp16` 检查点，以及 h3-relay 的遮罩选择、恢复和扩张节点。模型与第三方节点需另行安装；此功能不会下载模型。SAM 模型和节点的授权应分别按作者官方条款核对，不能从项目许可证推定商用或再分发权限。

本次提取仅用 mock 分割器、临时合成视频和完全拦截请求的页面 fixture 验证。真实 SAM3.1 推理、GPU 性能和用户素材分割质量尚未验收。

必要的主线安全适配：提交与素材根切换共锁、完成任务缓存失效、完整提交锁、精确取消、保存作业身份后轮询、只读与项目切换守卫、每次导出生成新媒体引用。CPU 合成及 SAM3 图算法沿用运行时源实现。
