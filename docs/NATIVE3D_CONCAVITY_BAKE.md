# 通用凹部烘焙诊断与修复边界

日期：2026-11-04；本地开发，不发布。用户指出 256 采样结果的数处凹部灰斑，要求解决通用问题，不做单模型补丁。

## 诊断事实

输入为 `bake-256-20261104` 的同源高低模和2048贴图，不使用用户红圈作为修改坐标。

- 原有效覆盖内377个漏投之外，844个PNG像素蓝通道低于128，分布于45个低模面、57个连通块；量化前报告为829个切线负Z。
- 844点中188走首轮投射，其中158个高几何面背向低模投射方向。旧代码只统计，没有拒绝。
- 656走可见候选认证，其中627点的高平滑法线背向低模平滑法线；其高几何法线仍朝外，中位夹角约78度。小幅高模平滑偏转足以跨低切平面，不能直接把它们全部判成内层错配。
- 93个中心插值法线背向自身高模几何面，存在明确的半球一致性问题。
- 对真实输出TBN解码，22743个有效纹素的法线背向低模几何面。它与负切线Z、射线漏投是不同判据，不能互相替代。
- 解析夹具证明：首轮投射接受背向首交；强相反子采样法线仍可被平均为不存在的方向；几何平面使用朝向几何背侧的平滑法线发射AO射线，会出现大量自击。

证据目录：`.cache/native3d/concavity-general-20261104/diagnosis/`、`normal-audit/`。尚未逐点证明用户每个红圈对应哪一种原因。

## 分阶段处理

首个有界修复只处理可明确判错的几何条件：

1. 首轮投射对真实高几何法线执行朝向检查，拒绝背向/无稳定朝外方向的首交。使用已有认证流程寻找其他合法对应；不扩大cage、不直接取最近内层、不随意选第二个命中。
2. 高插值法线只有在背向自身高几何面或退化时，才回退到该实际高几何法线。与低模法线的负点积不作为自动翻转/截断条件；切向与正掠射不强制改正。
3. AO依据命中的实际高模几何半球计算，避免无效平滑法线将射线发进自身表面。此举改变AO采样定义，需要明确记录，不能声称只是提高采样。
4. 子采样跨层/强折叠只能先作为质量风险记录；没有确定连续表层归属时，不凭平均、多数投票或滤波宣称修复。

通用测试覆盖：前后薄层、反面首交、深槽/内凹转角、真实遮挡、平面不应自遮挡、无效高平滑法线、合法负低切线Z、切向/掠射和未命中。实际岩石仅作后续验证案例，不在算法中写入face ID、UV坐标或截图区域。

## 不能通过改贴图恢复的情况

低模若已经跨过凹口、失去槽壁或存在自遮挡/轮廓差异，法线贴图只能改变着色，无法恢复真实遮挡与轮廓。应检测并报告“低模几何不足”，下一阶段选择局部细分/贴合、投射笼局部修正或人工确认。不得把合法的负Z全部翻正来假装解决。

## 灰斑进一步定位

同机位自动提取平灰区域，按相机射线映射回低模与UV：567个屏幕像素无背面、无覆盖外、无漏投，高模同视线也有表面。抽取330个唯一灰区纹素，全部走认证fallback；其中一组121个纹素只对应1个高模位置，另一组205个只对应2个高模位置（坐标按1e-5量化）。因此可见性认证通过不能等同于连续的表面对表面对应。

另独立审查1772个面：UV退化=0、零纹素=0、整面miss=0，排除本案例整面未烘和UV零覆盖。嵌入GLB纹理像素与PNG一致。当前结论是表面对应坍缩，而非单纯采样不足；具体替代策略仍在小范围探针验证。

通用质量门禁需补充对应的空间分布/局部退化检查；不得以全局99.98%命中率自动接受大片灰斑，也不能用任意调亮掩盖。诊断统计中的face ID仅定位证据，不进入算法特例。
