# 采石场岩壁完整材质复测

文档版本：1.1.34。状态：本地研究与修复中；没有新的稳定版本发布。

## 目标与真实进度

花岗岩已经完成五档 LOD、自然 UV、4096 × 4096 材质及检查用导出。当前输入采石场岩壁与首次历史岩石全部 1,998,143 个三角形及面角索引对应，差异仅为导入浮点精度，因此本次就是首个模型复测。原始高模、UV、法线及八种原始贴图保留；原始文件不改写。目标仍为五档可用 LOD、基于原高模的结构分析、自然 UV 和 4K 材质。

当前采石场正式 LOD0 已通过检查并保存：99,999 面，完整自交检查为零。基于原高模的 PartField/角度/AO 切缝计划已确认，LOD0 自然 UV 已计算并保存到画布。LOD1 仍在处理局部交叉，LOD2–4 尚未完成；4K 烘焙尚未提交。诊断候选不作为合格模型交付。

LOD0 UV 独立核验保留全部面与面角对应，209 个岛，无翻面或已检测重叠。面积利用率 53.81%，岛间平均密度比例 1.000038；局部仍有拉伸及方向警告，数值通过不代替最终视觉验收。页面一次保存请求中断后暂停自动保存，UV 已恢复保存，烘焙来源连线仍待页面显式重试保存；无需重新计算 UV。

## 已确认的失败机制

- 原资产是开放表面，原有边界可以简化，但必须保持连通分量、边界环、拓扑及可核对的轮廓误差。固定边界坐标哈希会误拒正常减面。
- 原始高模含真实细小折叠；减面可能继承或放大交叉。这些交叉在历史高精度数据里也存在，不是 float32 噪声。
- 相同输入上已有候选的完整诊断分别发现 53、58、9 对交叉。保留边界/拓扑/法线的保护策略改善了结果，但单纯换种子没有解决此类缺陷。
- 删除整圈三角面后补平可能明显损伤凹槽，已拒绝此方式的越限候选。局部翻边保留顶点，可在小范围重新组织三角面；有时需要允许不增加交叉的中间一步才能找到解。
- “局部反向法线比例不得增加”不宜独立作为通用硬门。最近高模微三角可能来自原始折叠，须结合真实导入平滑法线与邻域证据。但新增真实反向面会产生烘焙风险，仍不能直接放行。

## 实施与研究的边界

生产代码已经接入一次有界保护回退，并通过 73 项测试和独立代码审查。默认 Open3D 路径成功时保持原逻辑；仅默认 LOD0 阻断、没有已接受的 LOD0、可选运行库存在且同一个总时间预算仍有余量时尝试一次保护路线。该路线从实际原高模复现小范围源缺陷处理、每步最多约 50% 减面、完整交叉定位、局部翻边与必要的内部顶点有界移动；最后重新经过实际导出精度下的几何、边界与原高模保真度检查。后续各档仍逐级执行原 Open3D 路线，不锁死所有原始边界顶点。

真实原高模到保护候选的独立测试耗时 141.859 秒，99,999 面结果与已审候选哈希相同。实际画布任务已完成，包含默认路线失败和保护回退的总耗时为 243.094 秒；正式结果通过几何门，材质视觉验收尚未完成。

PyMeshLab 为 GPL 组件，仅安装在本机可选运行目录，未加入发布依赖。每次加载校验固定 wheel 和实际安装映射中的 186 个文件（182 个运行文件）。缺失时沿用原路线，损坏时明确记录回退失败，不将依赖错误当成成功。失败尝试仅在本任务目录内部留档；计划但未生成的文件不假称存在，已有成功档位不因后来失败而重算。

每个修补须记录原输入、实际改动、误差和检查结果；保留外轮廓、未修改区域及原始素材。最终可见 LOD 仍需独立检查完整自交、拓扑、边界、原高模保真度与规范化导出。成功档保留，失败档单独处理。
