## 发现与关闭

### R1 — [P2，已关闭] 圆柱 Corner UV 被统一重建破坏

初审位置：`pcg_geometry.py` 原第 118 行。圆柱绕序修正后按顶点索引统一重建 UV，丢失侧壁接缝处的 `u=1`，并把端盖边缘错误地映射成侧壁坐标。

复现：`evaluate('primitive', {'kind':'cylinder'}, {})['geometry']`。修正前 `triangles[28:30]` 的六项 UV 是 `[[.875,0],[.875,1],[0,1],[.875,0],[0,1],[0,0]]`，最后 45° 侧壁跨越 87.5% 纹理宽度。端盖边缘还全部落在 `v=0` 或 `v=1`，造成纹理采样与导出失真。

修正核对：当前 `pcg_geometry.py:111` 起在翻转三角形时同步交换对应 Corner UV，保留原侧壁展开与端盖投影。新增 `test_cylinder_corner_uv_seam_and_cap_projection` 和 `test_decoded_cylinder_uv_seams_and_caps` 覆盖不同细分、非均匀尺寸及独立 GLB 解码。几何/Field/导出 32 项独立复测通过，最终完整 PCG 测试也通过。
