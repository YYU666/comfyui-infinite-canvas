# 四视图：头像、身体与背面参考

2026-11-08。原生第三方四视图节点与可导入工作流包支持三个明确的图片角色。

## 连接方式

日常面板只显示参考图入口、生成按钮和最终结果。原生节点另提供可选的身体格补充要求；模型、采样、各格提示词、比例和裁切等设置默认折叠在“高级设置”中。新节点默认运行完整四格；已有单格节点明确标出当前单格，不因收起界面而修改保存的模式。

- **头像 / 单图参考**：接正面头像，决定人物身份、脸部、发型。原生节点继续使用旧 `guide` 端口，已有连线不迁移。
- **身体比例 / 穿搭参考（可选）**：接身体参考，决定体型、腿与躯干比例、服装和鞋。原生端口为 `body_reference`。
- **背面参考（可选）**：接背部服装与结构参考，原生端口为 `back_reference`。只作用于背身生成，保持正面身份和身体比例。可独立于身体参考使用。

接入第二张图后，原生节点显示双参考模式。它不套用白发女性固定配方中的外貌、短裤、九头身等角色专属默认值；需要额外文字要求时切换通用模板填写。未接第二张图时，原有单图配方继续按原方式执行。

从已验收固定配方接入身体参考时，保留其模型、40 步采样、1536 参考分辨率、CPU 缓存及各阶段种子，只替换角色专属提示词和不适用的头像裁切。两张图接好后可以不填额外提示词，按参考直接运行。

## 内部顺序

1. 从头像参考生成正面近景头像；按用户配置可先裁切头像参考。
2. 以保存后的正面头像生成 45°近景头像。
3. 以身体参考为图 1、保存后的正面头像为图 2，生成正面完整身体。图 1 决定身体比例和穿搭，图 2 决定身份；输出仍为正面全身构图。
4. 用保存后的完整正身生成背身，延续同一体型和服装。有背面参考时，它作为第二张图约束背部穿搭、接缝和结构；不接时保留原来的背身工作流及提示词，不把正面图当成背面参考。
5. 仅在最终交付时裁切身体格为不含头部的身体图，再拼成四格。画布只显示最终拼图。

身体参考先等比补边到 1152×2048，不拉伸身体来凑画幅。身体交付裁切仍可调整，适应不同身材与模型生成位置。参数与图像角色约束不能代替对实际生成结果的验收。

## 节点库与兼容

新双参考包使用阶段协议 v3，包含明确的外部输入角色。库内端口为必填的 `image_identity` 和可选的 `image_body`；后者缺失时使用身份图作为身体来源，支持单图运行。两个端口即便连到同一文件，也保留各自角色，不根据文件名猜测。

新增背面入口的本地包为 v0.4.0，使用阶段协议 v4，另含可选 `image_back`。缺失时选择独立保存的无背参分支；只执行一个背身分支，采样、种子和模型参数在两个分支同步。最终仍只输出一张拼图。

旧 v1/v2/v3 包及画布中的固定版本保持原执行定义。新通用双参考包的单图回退不宣称与旧白发角色专属配方像素一致。需要双参考时从本地节点库添加新版本。

阶段内部的已生成参考图仍通过保存、重新载入的边界传递。包导出、导入及准备执行均校验角色绑定、依赖和最终输出，不会将中间图片当成额外画布结果。

## 可选完整发型补充（第三方本地 v0.6.0）

四视图无法展示完整长发时，可另外添加「完整发型补充 · 可选六格（长发看不全时）」。这不是官方节点或默认六格模式；短发和四格已足够的角色无需使用。

必填入口为「已验收四格」「原始正面截图」「原始背面截图」。只补纯发型正背两张，去除人物，右侧追加为 3 列 × 2 行；原四格不重绘、不缩放、不裁切。旧四视图定义及工作流文件保持不变。当前必须提供真实背参，不能以正面冒充背面；等比适配会保留发梢，但生成内容仍需人工核对。

标准图行高默认均分；历史非等高拼图需填写上行高度。14 项自动化测试通过，本机已安装且画布草稿已保存；尚未进行新 GPU 生成或视觉验收。当前普通工作流不支持单格阶段断点恢复，批量列表及逐格接受/拒绝也未完成。未公开上传此包。

## 验证范围

验证包括旧单图配方工作流一致性、两张不同参考图、同文件不同角色、断开身体参考回退、单阶段重试、包导入导出及可选输入回退、隔离页面的连接入口。自动化测试不代表新人物的视觉效果已验收。

背面入口验证还包括全部可选输入组合、同文件多角色、断开背参后的精确回退、单独背身重试，以及两个分支共用参数。未为本次接口修改提交真实 GPU 生成。


## 原图身份优先与白边修正（本地 v0.5.0）

新增 `characterSheetIdentityMode=source-anchored-v1`。现有已保存节点与 v1–v4 包保持原定义，新建原生节点采用原图身份优先，可选择保持参考风格或摄影写实并调整强度。摄影写实默认强度为 0.45，不保证精确身份匹配；不使用角色专用辫子、发冠或服装描述。

- 正面头像仅一次采样，不先以强 LoRA 生成另一张脸再反复重绘。
- 45°头像同时读取已保存正面头像和原始身份参考，两个角色明确分离。当前原图优先模式不支持单独45°重试，明确提示使用四格整表；不得将同一张生成图冒充两种参考。
- 头像参考采用等比居中裁满，可填写原图像素 ROI；不向模型输入白色补边。居中裁满不是自动人脸检测，偏心构图应调整取景。身体、背面及交付裁切仍遵循原定义。
- 阶段协议 v5 明确身份角色及可选输入分支。v0.5.0 本机包四个生成阶段均使用0.45写实LoRA，模型/采样参数可调整；旧节点不会静默换版本。
- 接口/回归测试通过不等于人脸相似度或角度已通过视觉验收。当前实图显示单次生成较此前0.8两次重绘保留更多原图特征，但侧脸转角和身份仍需要人工确认。

本次红裙已生成图采用原像素裁切去掉顶部375行白边，输出2304×3721，未重绘主体。浅蓝角色使用单次原图头像与原图约束侧脸，身体两格复用已有结果重新拼接，输出2304×4096。它们是本次项目修正，不是承诺全自动质量门已解决。
