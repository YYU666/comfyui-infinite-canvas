# UV利用率与AO依据对照（1.1.14，本地验证）

用户澄清：方正的目的在于提高图集利用率，不能以严格固定方向或矩形包围框规整为理由留下大块空白。仍须保留合理岛数、间距、几何连续性、相对纹素密度及可接受拉伸。

## 实现

- coherent 的 `packingMode=efficient` 比较原矩形布局、多排序/90度旋转矩形候选与真实轮廓候选。轮廓采用512格保守掩码、3种排序、9步共同缩放搜索，最多256岛；超过预算跳过轮廓候选并记录原因。没有最优保证。
- 只作整岛0/90度旋转、平移及统一缩放，不改变几何或岛内形状。候选只有在三角形实际占用提高且重叠、越界、间距检查通过时选用；失败保留矩形方案。`legacy_fixed`可对照旧布局。
- 面积采用真实UV三角形面积，另有像素覆盖和float64三角形相交/线段距离检查；不是包围框占用。面积容差1e-12 UV²，不能宣称数学上的无限精度证明。
- AO预览直接读取原任务保存的faceDarkness、信号哈希和seamReasons，并核验原请求参数、源快照及几何哈希。高模仅流式验SHA，渲染使用低模；不重算、不平滑伪造原AO依据。
- AO依据、候选缝、最终缝、棋盘、UV图集、灰模分别显示。橙色候选为AO支持凹缝，紫色为粗块面边，黄色为必要/手工/分区等辅助边。最终UV缝可能包含展开器附加切缝。
- 所有模型缩略图双击放大；360px紧凑卡片、4:3预览，设置折叠，保留失败/运行状态和待复核提示。UV显示岛数及实测覆盖率。

## 真实样本的离线复核

复用同一个1772面LOD0、相同分区标签和展开参数、1024图集、8px间距。58岛样本实际占用38.9648%→60.1231%，岛数与几何不变，P95拉伸约1.20761、纹素密度P95/P05约1.53635。重叠/越界/间距违规均0。25岛旋转90度，最终局部反向面积约16.01%，因此不能称方向统一或生产质量已通过。45岛样本未取得收益，保留36.3173%旧布局，不能声称其空白问题已经解决。

原AO任务实际候选455边段：63段AO支持凹缝、390段粗块面边、2段极端角辅助边。原AO每面中心1点、32条射线、有限半径0.08；逐面采样有斑驳，可能漏掉窄槽。展示的是实际使用过的信号，不是最终高质量AO烘焙贴图。

离线证据 `.cache/native3d/uv-occupancy/offline-summary.json`；当前页正式交付证据由同目录 `delivery.json` 和最终核验记录补充。所有模型与源素材留在本地，未上传或发布。
