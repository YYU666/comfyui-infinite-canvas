# 公开视频导入核验

抖音浏览器回退导入只接受与目标作品 ID 匹配的页面元数据，不再选取页面上任意推荐或占位视频。短视频按作品真实时长校验；不会因为“只有两秒”便一律拒绝。

下载后使用已安装的 FFmpeg 完整解码视频轨，并将视频轨实际时长与作品元数据比较。解码失败、截断、时长不符和伪装成 MP4 的播放列表均被拒绝并删除本次输出；已有文件仍使用排他创建，不能覆盖。导入器继续使用原有公开网络代理、公共地址校验、体积限制，以及临时独立浏览器上下文；不读取用户浏览器配置或持久登录会话。

错误与清理路径不回显签名 CDN URL、解码器 stderr 或本机路径。launcher 仅新增 FFmpeg 参数并收紧错误回显，保留 main 的服务、项目、队列和更新逻辑。

离线测试使用模拟元数据/下载执行器、mock launcher 子进程，以及本机 FFmpeg 生成的合成小片段。没有启动浏览器或服务、操作用户画布、下载远端媒体或权重；真实网站可用性和作品下载仍需后续验收。
