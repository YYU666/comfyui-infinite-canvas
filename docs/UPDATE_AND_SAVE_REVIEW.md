# 更新通知与保存可靠性复核

本次检查覆盖更新发现、通知与设置、升级准备和回滚、素材导入、项目读取迁移及画布保存。重点处理可复现的并发覆盖、错误实例操作和重复升级问题；这不是对全部模型、第三方节点或真实线上升级的完整验收。

## 功能

- 自动检查启动后执行，此后每 4 小时检查一次；页面隐藏、离线或正在处理更新时延后执行。
- 自动发现更新显示非阻塞提示；忽略同版本后不再自动提醒，手动检查仍可用。
- 修改自动检查设置即时生效。没有正式 Release、网络不可用、旧后端缺少更新接口分别说明。
- 通知来源仍为官方 GitHub Release；代码提交和合并不会直接触发用户更新。

## 已修复的问题

| 问题 | 触发条件与后果 | 修复与验证 |
| --- | --- | --- |
| 素材上传绕过画布版本保护 | 旧页面上传素材后采用服务器最新 revision，下一次保存可能覆盖另一页面的新节点 | 浏览器上传携带原 revision；上传结束及重复素材返回前校验。合成测试覆盖旧页面、上传中修改和去重上传 |
| 读取兼容数据覆盖并发保存 | 读取触发迁移回写时，可能把期间提交的新文档覆盖回旧版本 | 整个读取、迁移和回写使用项目的可重入锁；并发回归测试确认最终新内容保留 |
| 重复升级准备 | 两个客户端在预检查期间同时申请升级，可能各自启动构建和替换流程 | 在预检查之前原子占用升级状态；双线程测试确认仅一次进入，失败后可重试 |
| 更新路径越界 | 程序子目录是指向外部的目录链接时，词法路径检查无法保护外部文件 | 检查各级目录链接及解析后归属；临时 junction/symlink 哨兵测试验证外部文件不变 |
| 回滚误认或误停其他实例 | 更新期间另一实例接管运行记录，健康检查或停止操作可能使用错误 PID | 绑定本次启动进程的 PID，测试错误实例不会被接受或停止 |
| 不同安装目录混用旧清单 | 共用运行目录下，另一安装的文件清单可能参与当前目录的旧文件删除 | 清单按规范化安装目录隔离，且验证目录归属；不采用归属未知的旧共享清单 |
| 已更新的 Git 安装无法再次升级 | 更新器替换程序后形成工作区差异，被下一次升级误判为用户修改 | 只接受与本安装已安装清单哈希完全一致的更新器差异；用户改动和暂存修改仍阻止升级 |
| 没有发布版本时提示连接失败 | GitHub latest Release 返回 404 | 返回独立的“尚未发布”状态；连接错误保持单独处理 |
| 长准备或响应丢失时误判升级失败 | 下载和构建超过普通读取超时，或客户端收不到升级响应 | 升级请求采用独立的长超时，准备期间持续显示状态；响应不明确时核实结果，不自动再次提交。合成 UI 测试覆盖超过 30 秒的准备和断线恢复 |

## 验证边界

并发、恢复与更新 UI 测试使用临时目录、合成项目、合成 Release 和模拟进程。测试不会提交真实生成、访问用户画布、安装真实更新或重启 ComfyUI。发布新版本时仍需上传更新 ZIP 和 SHA256，并完成隔离环境的真实升级验收。
