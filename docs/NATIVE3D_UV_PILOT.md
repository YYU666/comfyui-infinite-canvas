## 结论与未做

PartField分区比本例SAMesh更有用；8区拉伸略低，12区密度更均，4区岛数更少但密度差更大。所有结果仍有大量碎岛，尚未达到规整块面和隐蔽切缝的生产目标，不自动选岛数最少者为最佳。下一步在PartField8/12与AO基线上做缝线简化和小岛合并，同时约束拉伸/密度；先验收LOD0再传播共享atlas到LOD1–4。跨LOD UV共享、贴图转移、烘焙本轮未执行。
