# UV整合与LOD来源修正 · 2026-11-04

对应计划1.1.11。Decision：accept本轮实现、实验和当前页交付；revise生产UV质量。仅本地开发，不提交、不推送、不发布。

## 来源修正

五级LOD文件此前均来自同一个已接受的连续减面任务，误在画布上从该任务选中的800面结果扇出。现改为实际repair_lod处理器的“阶段输出”实线，以及原始高模的“高模参考”虚线；没有用800面恢复1772面，也没有重新生成高模或减面。

各卡片保留真实阶段、前序阶段、前序哈希和面数：fit1772→1200→800→500→300。每张缩略图用该阶段GLB独立CPU深度缓冲渲染480×360，通过当前页保存，不能共用800面预览。后端只允许成功且accepted的修复任务、登记阶段、匹配文件SHA，独立预览缓存不写项目。

## 展开整合

新增coherent选项，不改变structural/ao_geometry默认行为。允许取消过度细分的角度硬切缝，保留手工缝及可选PartField分区，放宽xatlas成岛偏好。chartMergeCost是合并偏好，不是拉伸上限。按每岛面积加权的世界+Y投影转向UV上方；水平面使用显式+Z/+X后备方向。按每岛3D/UV平均面积归一化密度，再使用禁止旋转的MaxRects打包。整岛平均方向统一不意味着曲面上每个三角形全部同向。

同一1772面LOD0、1024图集、8px间距；新任务均由当前可见页提交并交付，未改变几何三角面。不是复制离线试算冒充生成。

另一个38岛试算出现77重叠像素，已拒绝，没有放入当前画布。没有按岛数最少自动选择最佳结果。

## 验证与边界

64项相关Python测试通过；预览缓存完整性修正后7项预览/证据测试通过；阶段节点前端测试与local-tools构建通过。独立CPU和几何复核通过。两次模型可见图片检查累计522173字节，第二张为本次实际任务生成的108/45/58岛对照；观察到A大块更连续但棋盘大小不均，B棋盘更均匀而局部方向欠佳。
