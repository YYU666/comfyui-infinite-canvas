## 验收边界

本次是源码、合成网络、临时文件及并发回归验收，不等于真实 GPU 长跑、真实视频网站端到端验收或真实安装更新演练。需要外部下载器、原生 HTTP 之外的协议、浏览器指纹模拟或 JavaScript 挑战运行器的视频，安全下载路径会明确失败并提示手动下载后上传。普通 HTTP、原生 HLS/DASH 和本地音视频合并仍保留。工作台自身的 ComfyUI/侧栏 loopback 通信不受独立下载 worker 的网络限制影响。
