# 桌面启动与断线恢复验收

日期：2026-11-03。基线：`147655e`。本次不修改版本号、不发布 Release。

## 完成范围

- Windows 安装时创建「Refmuse 画布」桌面快捷方式，使用现有绿色 R favicon 转换的多尺寸 ICO。快捷方式记录实际工作台和便携版 Python 路径，双击启动或复用服务并打开网页。
- 当前用户注册 `refmuse-canvas://start` 固定协议，断线按钮同步调用它并留在当前页等待连接。协议入口不打开第二页，不重启健康服务。
- 新协议检查合并注册表中是否已有其他所有者，仅写 HKCU；保留其他应用的 `refmuse` 协议。URL 严格白名单，不接受命令、路径或额外参数。
- 重连刷新 HttpOnly 会话、恢复进度通道，保留桥接会话、未保存编辑和原 CAS 版本，不重放生成或失败的保存。外置项目仅在当前页已知路径且 GET 404 时重新登记，锁冲突不降级或覆盖。
- 修复 Windows 并发启动时锁字节初始化竞争；慢响应但仍存活的实例禁止重复启动；保存非敏感的上次端口以支持正常停止后的原地址恢复。

## 使用边界

- 当前已打开页面需刷新一次以加载新版按钮；浏览器第一次调用本机协议可能需要用户允许。
- 仅 ComfyUI 未就绪时单独提示，不能通过本入口强制重启正在运行的 ComfyUI。
- 若原端口在停机期间被其他程序占用，无法保证原页面地址恢复；快捷方式会打开服务实际使用的地址。
- 更新已有安装后可按 README 的注册命令补建快捷方式；移动程序目录后应重新注册。
