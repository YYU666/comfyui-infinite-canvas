# 项目素材文件定位

素材节点已有 `assetPath` 时，“打开文件位置”定位当前项目内的素材。即使节点仍留有旧的 ComfyUI 输出文件名，也以项目素材身份为准。普通 ComfyUI 输入、输出和结果 URL 的定位方式继续使用原有逻辑。

新素材定位接口只接收当前项目的内容寻址相对素材路径，校验项目身份、文件存在性与路径边界，拒绝链接及 Windows 重解析目录。Windows 使用 Unicode Shell API 选择文件，避免含空格、中文的路径被命令行错误解析；响应不回显本机路径。项目文件本身的定位入口继续沿用原实现，认证和同源校验继续经过现有请求入口。

此候选从运行时提取最小接线，额外收紧了链接、失效项目与异常信息处理。验证使用临时合成项目、mock Shell 和 mock fetch，没有打开 Explorer、启动服务或操作用户画布；真实桌面选择效果仍需后续人工验收。
