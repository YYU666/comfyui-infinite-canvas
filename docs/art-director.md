# 电子主美 · 图解分析

电子主美把一张作品、创作目标和可选参考转成可编辑的审图标注与 PNG 分析板。原素材保留；PNG 为本机生成的静态衍生图。模型判断、手工导入与操作示例分别显示来源。

## 从作品到 PNG

1. 在图片素材或图片结果上点击「电子主美 · 图解分析」；也可从添加菜单创建节点，把图片连到「作品图片」端口。
2. 可再连接最多三张参考图，并分别选择配色、构图等用途。填写「创作目标」和「必须保留」。
3. 选择视觉供应商，在配置面板输入对应 API Key，选择本次后端会话或 Windows 本机加密保存。模型和端点使用固定官方配置，详情见 [供应商与凭据](art-director-providers.md)。
4. 点击「分析并输出解析图」。云端会接收作品及所选参考；解析通过结构验证后，浏览器在本机排版并保存 PNG，画布中出现一个有连线的下游图片结果。
5. 可在节点内下载 PNG 或放大查看。后续输出复用同一个下游节点，旧 PNG 文件继续保留。

解析板包含带编号标注的原图、关联局部、灰度与直方图、量化色板、参考图及用途，以及逐条观察、影响、修改动作、保留项与不确定性。灰度、直方图和色板是本机测量；透视线、视觉焦点及审美建议需人工判断。

## 无密钥试用与 JSON 导入

连接作品后，点击「加载明确标识的示例」可以练习编辑和 PNG 输出。示例会明确显示「未进行模型视觉审查」，不代表对作品的实际模型判断。也可下载 JSON 模板、填入人工或其他来源的结构化解析，再通过「导入解析 JSON」加载；来源需要用户确认。

这些操作、标注编辑和 PNG 排版均在本机完成，无需付费云端请求。JSON 必须匹配当前作品版本、规定字段和归一化坐标；导入失败不会替换已有解析。

## 编辑辅助线与版本

点击原图中的线或框后可以拖动，或输入 0–1 范围的端点坐标。关联框移动时局部裁切一起更新。可修改文字、添加候选线、隐藏、删除和撤销标注编辑，再点击「保存标注」。隐藏／删除定位辅助线会保留对应文字和局部；辅助线位置为估计，可人工修正。

编辑标注后需重新输出 PNG。更换作品、参考、参考用途、创作目标或保留项会清除旧版本的可编辑解析，并把已有下游图片标记为「旧版解析」。原图和旧导出文件保留；请重新分析或导入匹配当前版本的解析。

## 凭据、取消与验证范围

密钥不随项目、剪贴板、导出包或状态接口保存。会话凭据在后端重启后清除；Windows 当前用户 DPAPI 加密持久化位于仓库和所有项目目录之外。非 Windows 系统可用会话或环境配置，持久化不可用时不会回退明文。

点击云端分析会向供应商发送图片。取消仅停止本机接收／应用结果；已经发出的请求可能继续执行和计费。当前发布使用合成图片、模拟接口、真实本机加密和隔离 UI 验证，没有进行真实付费视觉推理或账户权限测试。
