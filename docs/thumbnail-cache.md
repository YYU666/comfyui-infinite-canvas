# 画布节点缩略图缓存

图片节点和节点工具栏中的参考图只显示最长边 640 像素的 WebP。进入可见区域后才请求 `/api/thumbnails`，离屏节点不读取原图。打开项目只恢复素材 URL，不把全部素材预读为浏览器 File。双击大图、遮罩编辑、下载和生成引用继续使用原图；缩略图 URL 不写入节点数据或项目文件。

浏览器把可见缩略图请求限制为最多 2 个并发，同 URL 的节点共享请求和预览对象。移出视口时取消尚未完成的读取；已成功的预览保留至节点卸载，最后一个使用者离开后才释放。503 繁忙响应自动退避重试最多 2 次（300/900 毫秒），持续失败才显示手动重试；不会把整页冷缓存请求同时压入后端。

后端把派生图写入工作台运行目录的 `thumbnails/`，与原图和项目分开。缓存可删除后自动重建，不属于项目备份。缓存身份包含编码版本及源身份：项目素材使用授权项目路径、字节数、纳秒修改时间和创建/元数据变化时间；ComfyUI 素材只访问后端配置的固定服务 `/view`，通过其 ETag、Last-Modified 和大小验证，不猜测外部 ComfyUI 的磁盘目录，不接受任意 URL，不跟随重定向。相同源在服务重启后复用磁盘缓存。

ComfyUI 有 ETag 时，命中只发送 HEAD，不传输或重新解码原图。缺少 ETag 或不支持 HEAD 时，每次请求都以有界临时下载和内容摘要验证，再复用已有派生图，避免永久显示过期图。第一次生成 ComfyUI 缩略图仍需在后端读取一次原始文件。临时原始数据在请求结束后删除，不存入缩略图目录。

资源限制：同时最多 2 个源读取/解码任务；等待超过 1 秒返回繁忙；源文件最多 128 MiB、解码最多 64 百万像素。编码采用临时文件加原子替换。缓存定期按时间清理旧 WebP，目标上限 512 MiB（检查间隔 60 秒，写入高峰可暂时超过）；清理范围仅该缓存目录，不触碰原图或用户文件。

无法生成缩略图时，节点显示“缩略图未加载 · 重试”，不会自动下载原图作为回退；用户仍可双击查看原图。浏览器 HTTP 缓存通过 ETag/304 验证，保持现有 `Cache-Control: no-cache` 策略。

验证：`python -m unittest test_thumbnail_cache` 覆盖跨实例命中、源变化、安全边界、资源限制及受保护 HTTP 路由；`node test-canvas-thumbnails.mjs` 校验素材身份；构建后运行 `node test-canvas-thumbnails-ui.mjs`，使用完全拦截的合成页面验证 102 张图打开和刷新均不读取原图、离屏延迟加载、失败重试，以及完整原图预览和有序生成上传。所有夹具都不访问用户项目或实际 GPU。
