# 绿幕扣像合成

依赖 E1 CPU FFmpeg 基础层；本候选 stack 在节奏节点之后。fg 连接视频，bg 可连接图片或视频。参数和双键色、去溢色、收缩/羽化、前景位置、背景适配、保留音频及预览算法沿用 runtime。Agent 预设 video_chroma_key，导出走当前页面的版本素材提交。

取消、失败保留旧成片；复制清理导出身份，撤销保留当前导出身份。切换项目根目录会清空旧后台任务，防止旧成片提交到新目录。此补丁同时将节奏后台接到相同保护。预览为单帧 CPU 运算，正式导出为本地作业，不调用 ComfyUI。

合成测试只使用临时目录内的合成图像和音视频，不代表真实用户素材效果已经验收。
