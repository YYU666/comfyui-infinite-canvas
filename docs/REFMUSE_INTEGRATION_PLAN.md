# Refmuse 官网与本地工作台整合开发计划

- 版本：v1.0
- 日期：2026-10-29
- 状态：规划稿，尚未进入实施
- 现有本地基线：`video-workbench` / `web` / `v1.0.1-rc.1`
- 关联文档：`Refmuse-网页端-下载与开源内容-开发计划-v1.0.md`、`docs/OPEN_SOURCE_REMEDIATION.md`

## 0. 域名与命名前提

产品名暂统一使用 **Refmuse**。需求沟通中出现 `refmse.cn`，网页端计划中使用 `refmuse.cn`；M0 必须确认唯一正式域名，并在官网、深链、回调白名单、文档和签名配置中统一使用。本文统一称“Refmuse 官网”，不预先假定哪一个域名正确。

## 1. 总体决策

将原网页端计划的实施顺序调整为：

1. 先完成“搜索参考 → 导入本地工作台”的最小闭环。
2. 再建设 `/local` 本地版下载与安装页面。
3. 最后扩展 `/open` 开源内容中心、账号同步和作品发布。

现有本地端已经具备无限画布、素材管理、自动保存、网页视频链接导入、ComfyUI 队列及 Agent 接口。本计划复用这些能力，不重做本地生成底座，不改变现有换装、四视图、写实化和视频生成流程。

## 2. 产品定位与边界

### 2.1 Refmuse 官网

负责灵感发现、图片／视频参考搜索、收藏管理、本地版下载、开源内容浏览与分发。

### 2.2 Refmuse 本地工作台

负责参考素材导入、项目与画布组织、ComfyUI 生成、镜头／Take、导出和本地数据管理。

### 2.3 开源内容中心

负责模板、提示词、节点包和项目模板的浏览、审核、安装与更新。参考素材和开源安装包是两类不同内容，不共用安装语义。

### 2.4 v1 不做

- 付费商城、支付、订单和创作者分成。
- 云端与本地项目的实时同步。
- 默认上传本地私人素材或生成结果。
- 未审核节点包的自动安装。
- 为导入参考而绕过平台登录、反爬、地域或版权限制。

## 3. 品牌名称与图标

### 3.1 用户可见命名

- 产品与画布名称统一为 `Refmuse 本地工作台`。
- 浏览器标题统一为 `Refmuse 本地工作台 · 本地创作`。
- 官网下载页 → `Refmuse 本地版`。
- 导入按钮 → `导入 Refmuse 本地工作台`。

MiniMax H3、H3 工作流和 H3 模型等技术名称保留。现有 API、项目格式、模型清单和内部标识不做一次性批量重命名，避免破坏旧项目与第三方 Agent。

`h3wb` 命令和协议暂时保留；后续增加 `refmuse` 别名，旧入口经过兼容期后再决定是否弃用。

### 3.2 替换范围

启动器、网页标题、设置／关于页面、应用图标、favicon、README、截图、下载页、GitHub 仓库描述和 Release 展示信息。

### 3.3 图标方向

采用“R 字母＋播放符号＋画布节点”的简洁几何组合，保证小尺寸可辨认并适配明暗主题。不得使用参考网站或其他产品的图标、图片、商标和私有素材。

交付 SVG、favicon、Windows 多尺寸 PNG／ICO，以及官网社交分享图。

## 4. 第一期核心用户流程

```text
官网搜索参考
  → 查看图片／视频详情、来源与使用边界
  → 点击“导入本地工作台”
  → 唤起本地端并显示参考预览
  → 用户选择当前项目、已有项目或新建项目
  → 本地下载、校验、去重并写入项目资产
  → 自动创建图片／视频参考节点
  → 自动保存项目
  → 用户继续现有本地创作流程
```

第一期同时支持图片和用户有权使用的公开视频参考。无法唤起本地端时，提供本地下载页和手动下载／导入方式。

## 5. 官网端工作

### 5.1 参考搜索 MVP

在现有“灵感参考”入口上完善：

- 图片／视频统一搜索、分类和筛选。
- 详情页预览、标题、作者、来源、原始链接、标签和授权／使用边界。
- “导入本地工作台”主按钮及明确的导入状态。
- 空状态、加载、失败、取消和重试。
- 移动端可用性、键盘操作、焦点管理和基础 SEO。

### 5.2 导入凭证接口

官网为一次导入生成短期、单次使用的 ticket。ticket 只代表指定参考及版本，不包含本地项目信息、本地令牌或用户私人文件路径。

建议接口：

```text
POST /api/references/:id/import-ticket
POST /api/local-import/resolve
POST /api/local-import/complete
```

完成上报只记录导入结果所需的最低信息；统计与设备信息上报必须可选并有隐私说明。

## 6. 本地端工作

### 6.1 参考导入入口

新增参考导入确认页／对话框，显示参考预览、来源、文件类型、大小和目标项目。未经用户确认不得写入项目。

支持导入到当前项目、其他已有项目或新建项目；目标项目有活动任务或只读时给出明确状态，不强行切换。

### 6.2 资产与节点

- 图片创建图片参考节点，视频创建视频参考节点。
- 保存来源、作者、原始链接、授权信息和导入时间。
- 按内容哈希去重，重复导入复用已有文件。
- 大视频显示进度，支持取消、失败重试和断点续传。
- 写入采用临时文件＋校验后发布，失败不留下半成品引用。
- 导入完成后自动保存；关闭并重开项目仍可访问素材。

### 6.3 连接方式

首选自定义协议：

```text
refmuse://import?ticket=<一次性凭证>
```

本地端使用 ticket 向官网换取签名参考清单和下载地址。`h3wb://` 保留用于既有开源内容安装兼容，不把两种载荷混用。

参考清单至少包含：

```text
schemaVersion、referenceId、version、title、sourceUrl、creator、
license／usage、media[type, url, bytes, sha256]、preview、expiresAt
```

## 7. 安全与隐私要求

- 官网不能读取本地文件、项目列表、实例令牌或其他项目内容。
- 本地令牌不得出现在网页 URL、ticket、Referer、日志或分析事件中。
- 只接受 Refmuse 官方签发的参考清单，不允许任意 URL 导入。
- 下载强制 HTTPS；限制 MIME、大小、重定向次数和最终地址，阻止内网／回环地址及 SSRF。
- 校验 SHA256、路径和最终落点；拒绝路径穿越、符号链接和错误文件类型。
- ticket 短期、单次、可撤销；重复请求不能重复写入。
- 本地默认只监听回环地址，不因官网集成开放局域网访问。
- 私人素材默认不上传；发布作品、同步内容库和统计数据分别取得用户授权。
- 官网连接功能不得改变现有停止 ComfyUI、活动任务保护和项目锁语义。

## 8. 后续官网建设

### 8.1 `/local` 本地版

- 品牌统一后的下载页、安装文档、系统要求、FAQ 和版本记录。
- Windows 优先；macOS 仅按真实支持矩阵开放。
- 下载包、SHA256、发布后台、历史版本、下载统计和国内镜像。
- 发布包不包含模型、密钥、日志、项目或个人素材。
- 模型继续独立授权、独立下载和校验，不随源码包再分发。

### 8.2 `/open` 开源内容中心

- 优先支持 H3／Refmuse 模板、提示词包和不含私人素材的项目模板。
- 节点包后置，必须经过源码审核、权限提示、签名和重启确认。
- 支持首页、搜索、详情、创作者、内容库、提交、审核、举报和下架。
- 每个条目追溯 GitHub repo、固定 tag／commit、License 和可安装包。
- “安装到本地”复用连接层，但使用独立 `.h3pack` 清单、安装、更新、卸载和回滚流程。
- v1 全部免费开源，不引入支付和订单表。

## 9. 实施阶段与验收

| 阶段 | 工作内容 | 完成标准 |
|---|---|---|
| M0 品牌与基线 | 确认域名；统一命名和图标；锁定官网部署基线；整理兼容清单 | 双端品牌一致，旧项目和旧 Agent 入口不回归 |
| M1 参考搜索 MVP | 官网搜索、筛选、详情、来源和授权信息 | 图片／视频可搜索、预览和追溯来源 |
| M2 本地导入闭环 | 深链、ticket、项目选择、本地下载、资产入库和参考节点 | 搜索到画布的真实闭环通过 |
| M3 参考管理 | 收藏、标签、去重、导入历史、进度、取消和恢复 | 大文件与重复／中断场景通过 |
| M4 本地下载页 | `/local`、发布后台、安装文档和统计 | 干净 Windows 环境按文档安装成功 |
| M5 开源内容中心 | `/open`、提交审核、模板安装、更新与卸载 | 浏览到本地安装闭环通过 |
| M6 账号与发布扩展 | 设备登录、可选内容库同步、作品发布 | 默认不同步，授权和撤销有效 |
| M7 发布加固 | 安全、兼容、性能、SEO、监控、回滚与文档 | 双端发布验收通过 |

参考导入 MVP 预计 4–6 周；包含下载页和开源内容中心的完整版本预计 10–13 周。工期以基线确认后为准，不把未执行的 Mac、真实 GPU 或长跑验证写成已完成。

## 10. 第一期测试矩阵

### 功能

- 图片和视频分别导入已有项目与新项目。
- 导入后节点类型、预览、来源和项目资产引用正确。
- 刷新、关闭、重开和项目切换后数据一致。
- 重复导入复用文件，不重复创建素材副本。
- 取消后立即重试不会被旧请求覆盖，不产生重复节点。

### 故障与安全

- 无效／过期／重放 ticket、错误签名、哈希不符和超大文件均拒绝。
- 重定向到内网、回环、非 HTTPS 或不支持类型时拒绝。
- 下载中断、磁盘不足、项目只读、活动任务和保存失败均有可恢复状态。
- 官网无法通过导入接口枚举本地项目或读取任意文件。

### 回归

- 现有换装、四视图、写实化、视频生成、Take 和导出流程不变。
- Python、Node、浏览器和构建测试通过；从干净 Git 导出内容复验。
- 测试只使用合成素材和临时项目，不读取真实私人项目。
- 当前暂停的 QA-03 长跑保持暂停，不因本计划自行恢复。

## 11. 数据与指标

只采集改进搜索和导入所需的最少事件：搜索成功、详情打开、导入发起、导入成功／失败和错误类别。默认不记录素材内容、私人文件名、完整 URL 查询参数、本地路径、IP 明文或令牌。

核心指标：搜索到详情转化率、导入发起率、导入成功率、失败原因、重复素材节省空间，以及导入后的首次本地生成。不得以指标为由默认开启本地内容上报。

## 12. 当前建议

优先实施 M0–M2，先证明“搜索参考 → 本地画布”真实可用，再扩大内容中心和账号能力。品牌替换与接口兼容可以并行，但不得借改名批量改写内部模型名、项目格式或 Agent 协议。
