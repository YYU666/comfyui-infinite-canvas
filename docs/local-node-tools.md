# 本机第三方工具与公开版本

「母图编辑 V2」「角色替换」「角色四视图生成」及旧版四视图换装预设属于尚未验收的工具，不再作为官方节点预装。旧画布的节点、参数、结果和兼容执行代码保留；这不代表其效果已通过稳定版验收。

公共 `npm run build` 和普通开发模式不会读取本机工具清单。公共右键菜单、Agent 创建列表均不注册这些预设。用户自行从节点库安装的工作流仍可通过「第三方工具 → 已安装的节点工具」添加；安装文件保存在用户数据目录，不属于源码发布内容。

本机调试使用被 Git 忽略的 `.local-node-tools/presets.json`，内容为条目数组，每条只包含已有预设的 `preset`、显示名称 `label`、可选 `description`。仅显式运行 `npm run build -- --mode local-tools` 才会读取该文件。没有文件或配置错误时构建失败，不自动生成实验预设。

发布与 CI 必须使用普通构建。更新包脚本额外拒绝本机工具目录、`.h3pack` 私有工作流包和构建缓存，即使误用强制添加 Git，也不能带入更新包。不要将模型、参考图、个人提示词、输出素材或凭据写入工具清单和提交。
