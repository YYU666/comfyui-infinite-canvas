## 固定制作顺序及参数

1. 导入结构高模及带材质高模，保留各自用途与来源。
2. 逐级减面，从上一级生成下一档；可单档重试，不重跑整个链路。
3. PartField AI 分块 → 凸角切分 → 凹角/AO 辅助切缝 → 用户检查方向与切缝 → 展开和统一密度排布。
4. UV 低模连接烘焙低模口，带材质高模连接高模口，输出五张 4K 贴图。
5. 结果保存在处理节点内，支持贴图缩略图、原图和材质 3D 查看；不再另增通用重复结果节点。

本次成功减面链使用传统 Open3D/PyMeshLab 后端，不应误记为 MeshAnything 成功案例。AI 用于 PartField 分区。
