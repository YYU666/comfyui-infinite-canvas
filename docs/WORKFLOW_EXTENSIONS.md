# 自定义工作流节点

目标：用户的 ComfyUI 工作流可作为一个画布节点使用，不需要修改官方程序源码。官方更新和自定义节点分别保存。

## 第一版范围

- 导入 `.h3pack` 节点包或 ComfyUI **API 格式** JSON。编辑器的普通 `nodes/links` JSON 不能直接执行，需要在 ComfyUI 导出 API 格式。
- 图像工作流：多个图片输入、可编辑的基础参数、图片输出。三图输入分别映射到工作流的三个 `LoadImage`，不拼成一个输入，也不忽略多余图片。
- 导入只保存定义；点击节点运行后，才通过现有队列交给本地 ComfyUI。缺少节点或模型时提示具体依赖，不自动安装。
- 支持重新下载本地包，之后可以投稿到 Refmuse 节点库。投稿仍需登录，并按网站规则审核。

入口：顶部「节点库」→「本地节点 / 导入工作流」，或画布添加菜单中的工作流导入入口。选择文件、检查输入及参数后，点击「确认添加到当前画布」。将图片连到对应端口，调整参数，点击运行。没有指定再分发许可证的 API JSON 转换包会保留 `UNSPECIFIED`，不会代作者授予开源许可。

## 保存与升级

节点包保存到工作台运行目录 `extensions/`，默认位于 `%LOCALAPPDATA%/H3Workbench/extensions/`。若启动前配置了 `H3_WORKBENCH_RUNTIME_DIR`，则使用该目录。它独立于程序安装目录，不放在 `src/` 或 `dist/`。

画布项目保存节点包的 SHA256 标识、节点定义 ID、参数与连线；同一包再次导入复用原内容。不同内容产生不同标识，不悄悄替换旧项目依赖。迁移到其他电脑时，除项目与素材外，还需导入原节点包，并安装其 ComfyUI 节点及模型依赖。

官方升级仍会阻止覆盖本地源码修改。原先直接改源码的定制功能需要先导出并封装工作流，不能仅靠升级自动恢复；涉及自定义程序代码的功能也不等同于声明式工作流。

## 运行边界

包可描述 ComfyUI 图、端口、参数及依赖，不安装或执行包内 Python/JavaScript。只运行你信任且本机已安装的 ComfyUI 节点：声明式包并不是 ComfyUI 自定义节点的沙箱。

第一版不支持任意网页组件、包内程序脚本、自动依赖安装、可选图像端口、视频/音频/列表端口或任意编辑器图的自动转换。整数参数限于 JavaScript 安全整数范围（绝对值不超过 9007199254740991），避免种子静默变值。节点 `class_type` 仅接受字母、数字和下划线。不支持的协议和字段会在导入或运行前明确拒绝，不悄悄降级执行。

## 验收约定

导入校验、三图绑定、参数与依赖检查、队列完成后结果连回来源节点、项目保存/重开、程序更新/回滚后节点包可读，均需有测试证据。用户当前画布的生成验收通过当前页桥完成，不另开项目写入端。
