# 自定义工作流节点

目标：用户的 ComfyUI 工作流可作为一个画布节点使用，不需要修改官方程序源码。官方更新和自定义节点分别保存。

## 第一版范围

- 导入 `.h3pack` 节点包或 ComfyUI **API 格式** JSON。编辑器的普通 `nodes/links` JSON 不能直接执行，需要在 ComfyUI 导出 API 格式。
- 图像工作流：多个图片输入、可编辑的基础参数、图片输出。三图输入分别映射到工作流的三个 `LoadImage`，不拼成一个输入，也不忽略多余图片。
- 导入只保存定义；点击节点运行后，才通过现有队列交给本地 ComfyUI。缺少节点或模型时提示具体依赖，不自动运行。
- 节点库在画布右侧展开，关闭重开保留搜索。列表右侧下载按钮直接添加到当前画布；需要处理依赖时先显示检查窗口，保存成功后才返回已添加。
- 运行按钮前的上传入口可将单阶段图片节点封装为 `.h3pack`，自动整理模型、LoRA 与 ComfyUI 节点类说明。普通单阶段工作流默认清空提示词、不包含原图（可选公开缩略封面除外）；审阅包与文本参数后，在 Refmuse 登录并确认投稿，仍需人工审核。

入口：顶部「节点库」→「本地节点 / 导入工作流」，或画布添加菜单中的工作流导入入口。选择文件、检查输入及参数后，点击「确认添加到当前画布」。将图片连到对应端口，调整参数，点击运行。没有指定再分发许可证的 API JSON 转换包会保留 `UNSPECIFIED`，不会代作者授予开源许可。

## 保存与升级

节点包保存到工作台运行目录 `extensions/`，默认位于 `%LOCALAPPDATA%/H3Workbench/extensions/`。若启动前配置了 `H3_WORKBENCH_RUNTIME_DIR`，则使用该目录。它独立于程序安装目录，不放在 `src/` 或 `dist/`。

画布项目保存节点包的 SHA256 标识、节点定义 ID、参数与连线；同一包再次导入复用原内容。不同内容产生不同标识，不悄悄替换旧项目依赖。迁移到其他电脑时，除项目与素材外，还需导入原节点包，并安装其 ComfyUI 节点及模型依赖。

官方升级仍会阻止覆盖本地源码修改。原先直接改源码的定制功能需要先导出并封装工作流，不能仅靠升级自动恢复；涉及自定义程序代码的功能也不等同于声明式工作流。

## 运行边界

包可描述 ComfyUI 图、端口、参数及依赖，不安装或执行包内 Python/JavaScript。只运行你信任且本机已安装的 ComfyUI 节点：声明式包并不是 ComfyUI 自定义节点的沙箱。

第一版不支持任意网页组件、包内程序脚本、自动安装 Python 节点、可选图像端口、视频/音频/列表端口或任意编辑器图的自动转换。角色四视图支持完整分阶段分享；视频和其他多阶段队列暂不支持完整分享。整数参数限于 JavaScript 安全整数范围（绝对值不超过 9007199254740991），避免种子静默变值。节点 `class_type` 仅接受字母、数字和下划线。不支持的协议和字段会在导入或运行前明确拒绝，不悄悄降级执行。

## 模型依赖

导入时读取本机 ComfyUI 加载器选项。自定义画布节点的「检查依赖」可随时重新检查，按当前实例参数确认替换，不改变原包。

一键补齐仅支持本仓模型清单中有精确官方来源的模型，显示大小及校验等级，下载后校验且不覆盖已有文件。没有已核实来源的第三方模型需要按作者说明安装。下载可以收起窗口继续使用画布，重开恢复进度；任务不跨后端重启续传。

本地候选来自同一加载器，不等于架构、量化或效果兼容，须由用户核对后点击确认。已安装状态也只表示加载器可选，并非重新计算了本机权重哈希。自定义节点内部隐式下载的模型未必能从工作流常量识别，作者需要补充说明。

## 验收约定

导入校验、三图绑定、参数与依赖检查、队列完成后结果连回来源节点、项目保存/重开、程序更新/回滚后节点包可读，均需有测试证据。用户当前画布的生成验收通过当前页桥完成，不另开项目写入端。

## 角色四视图分阶段节点（v1.0.2）

角色四视图上传会保留正面头像、45°头像、背面全身、正面全身与最终拼接五个阶段。45°阶段仅使用已保存的正面头像，其余三张使用一个外部角色参考输入；导入后仍是一个画布节点，按原队列逐张执行。模型、LoRA、采样参数、独立种子及参考缓存设置随各阶段保留，依赖说明覆盖所有阶段。

这些视角指令是工作流的一部分，不能像普通单图工作流一样清空。上传或再次分享前必须勾选包含提示词，并审阅文本预览；其中也会包含当前角色描述，发布者应先移除不希望公开的文字。原始图片、完整阶段结果和模型权重不包含在节点包中；用户明确选择的压缩封面可随包分享。

包内使用带命名空间的 API 图保存所有阶段，并以节点定义的 `execution` 合同明确阶段边界。该图仅用于存储与依赖分析，不作为一次 ComfyUI 请求运行。工作台在准备阶段还原队列，校验阶段内连接、固定输入依赖和最终拼接输出；仅最终拼接图交付为节点输出。分阶段包要求 `compatibility.workbenchVersion` 为 `>=1.0.2`。

## 分享表单与封面

上传表单根据工作流用途自动概括名称和使用步骤，允许手动修改；不会把画布中的个人测试标题或提示词自动写入说明。许可选项附中文解释，默认不代替作者选择授权。模型、LoRA、第三方节点与封面图片遵循各自授权。

可以选择当前生成结果作为公开封面，没有结果时明确标注输入参考图；预览后可取消。封面仅为长边不超过512像素、128 KiB以内的JPEG，后端重新编码去除EXIF等元数据。原始输入图和生成原图不打包。封面保存在可选的manifest.preview字段，跟随节点包摘要及审核流程，网站目录、详情和投稿确认展示同一封面。再次分享不会自动继承旧包封面，必须使用当前选择。
