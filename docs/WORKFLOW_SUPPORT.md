# 工作流支持矩阵

## 前后端共享合同

`fixtures/video-workflow-contract.json` 是 H3 文生视频与全能参考视频的共享测试输入。Python Agent 与浏览器端必须使用相同的节点类型、模型文件名、尺寸／帧数／采样参数、引用顺序及输出文件名。`test_agent_workflow_contract.py` 会真实调用两端构建器并逐字段比较完整工作流，同时固定 Take 输出身份和 ComfyUI 外部引用格式。

| 模式 | 浏览器 | Python Agent | 合同范围 |
| --- | --- | --- | --- |
| H3 文生视频 | 支持 | 支持 | Turbo／完整采样、比例、分辨率、时长、种子、提示词 |
| H3 图片／视频／音频参考视频 | 支持 | 构建器支持；Agent 项目素材上传目前只直接支持图片 | 混合引用顺序、@标题替换、模型、VAE、参考参数 |

## 各自特有模式

以下是浏览器专用工作流，不因共享合同而声称已经迁移到 Python Agent：首尾帧、Krea2／MOSS 生图、母图编辑、Qwen 编辑、真人化、局部写实、换装、多视图、图片高清、精准角色替换、视频高清二采。

Python Agent 的 `frames_video`、图像编辑和换装预设只负责创建对应画布节点；其共享服务端生成构建器目前仅覆盖上表两种 H3 视频模式。需要执行浏览器专用工作流时，使用画布 WebMCP，不要把“节点创建成功”当成“Python 服务端已支持该模式生成”。
