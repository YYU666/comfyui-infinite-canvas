## 2. 概念设计与多图参考

- [x] 图生图使用统一图片接入口，当前实现支持 1–10 张参考。
- [x] 可以同时输入地编截图、场景参考、手绘风格参考，在提示词中说明各图用途。
- [x] 提供缩略图、参考顺序调整和「图1 / 图2」引用；排序改变后保持对原图片的引用关系。
- [x] 断开的图片引用、重复引用和超出数量限制会提示错误，避免静默生成错误内容。
- [x] 第一张参考决定画幅；保留生成精度、模型和种子等设置。
- [x] 图片结果信息显示实际尺寸，便于核对输出分辨率。

已确认的设计：LoRA 由用户自行搜索、选择和使用，本版不提供默认手绘 LoRA 组合，这不属于待补功能。10 张是当前接入上限，不表示任意显存和组合都已完成实机效果验收；原生可编辑分层 PSD 导出未纳入本版。
