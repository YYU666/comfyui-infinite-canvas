# 生成流程选择与验收

先用 `canvas_get_state` 识别当前母图、参考素材和已有处理节点。以下是节点选择原则，不是允许跳过真实结果核验的快捷方式。

## 1. 图生图与母图编辑

- `qwen_edit`：Qwen 2.1 图生图和基于指令的局部修改，默认参考分辨率 1024、步数 40。适合换装、姿势或明确区域修改。
- `realism_edit`：独立漫转真节点，固定 Qwen 2.1 与 `Qwen2.1_Anything2RealCharacters` LoRA（默认 0.8），用于把风格化人物参考转为真人摄影基准；先验收真人感和身份，再作为母图使用。
- `identity_edit`：母图编辑 V2，适用于需要保持人物身份并综合参考的编辑。
- `krea_image`：Krea2 生图或场景方案。
- `moss_image`：MOSS 新角色或场景生成方案；先确认依赖和模型已安装。
- `prompt_optimizer`：将自然语言创意优化后接入支持的生成节点；优化后仍须检查最终提示词。

局部修改时明确“保留什么”和“只改什么”。母图是身份、比例、妆容或姿势的基准时，不拿中间失败结果继续替代母图。

## 2. 局部写实修复

使用 `local_realism`，仅增强指定区域的自然皮肤纹理和真实光影，保留身份、五官、妆容、表情和非目标区域。

- 先确认输入确实来自用户认可的母图，而非其他测试图。
- 使用已有遮罩时核实它对应同一张输入图；不要用错图或错位置。
- 修复后对比面部结构和原始肤质，避免把“重绘一张脸”当作“增强写实”。
- 出现换脸、老化、浓妆或磨皮过度时，停止迭代并调整流程，不覆盖母图。

## 3. 换装与四视图

使用 `outfit_edit`。穿搭参考可作为输入素材，但最终必须核实衣服、鞋和身体结构，不只看提示词。

先确认母图版面，再生成：新建节点默认 `mixedGrid`（当前非等分四宫格）；等分四宫格用 `equalGrid`，横排用 `horizontal`，其他边界用 `custom`。自定义 `outfitPanels` 必须包含 4 个面板，每个面板以 `role`（`portrait`／`body`）、`view`（`front`／`side`／`back`／`threeQuarter`）和归一化 `x/y/width/height` 描述。旧项目未设置版面时保持 `legacy`，不要擅自迁移。通用版面逐面板换装，再按母图原尺寸和坐标回贴；不要把横排改成四宫格。近景只换可见衣服，不得拉远成半身；全身保持原裁切，不得给无头裁切补头，并保留各视图原有发型和头发长度。

四视图统一在一个结果中交付，避免散放多个无关联结果节点。高清按实际输出尺寸触发：长边低于 1000 像素才自动进行 SeedVR2 高清；达到 1000 像素及以上直接保留千问原图，不对 2K 头像或全身像重复高清。需要高清时，遵循以下顺序：

1. 分别生成并检查正面、侧面、背面等单视图，确认无头、无身体压缩、无错误补全。
2. 只对低于 1K 的单视图分别高清；不要在拼接后的整张图上重绘导致比例变化或把头部补回全身裁切图。
3. 核验四张最终单图后再拼接为最终四视图。
4. 最终图必须保持母图的身体比例、腰身和服装层次，不因穿衣自行加粗腰身或缩短腿部。

全身结构参考聚焦身体比例和穿搭，避免无意义地重绘面部。面部细节参考单独制作，不要用半胸像压缩脸部占比。

## 4. 图片高清

使用 `image_upscale`，默认倍率 1.5，可按任务调整。高清不是无约束重绘：

- 保留原始构图、身份、妆容、身体比例、服装和脚部姿势。
- 处理四视图前先按单张处理，再拼接。
- 输出 4K 目标时，确认最终拼接后的实际像素尺寸，不把“模型内部放大”直接称为 4K。
- 若高清改变身份或比例，保留原图，停止将该结果作为新母图。

## 5. 视频生成

| 需求 | 节点 |
| --- | --- |
| 综合图片、视频、音频参考 | `reference_video` |
| 指定角色替换到参考视频 | `character_swap` |
| 纯文本生成视频 | `text_video` |
| 首帧、尾帧控制 | `frames_video` |
| 已有视频高清二采 | `video_upscale` |

首尾帧分别核实 `first`、`last` 端口，不要依赖默认槽位猜测。生成前检查比例、分辨率、时长和提示词；完成后确认视频结果节点可播放且对应本次 `promptId`。

## 6. 通用验收

每次至少核验：

1. 输入就是用户指定素材，没有拿错测试图或中间废图。
2. 节点参数、提示词和连线与任务一致。
3. 终态为 `done`，真实结果节点存在，且不是旧结果。
4. 人物任务检查身份、五官、身材比例、服装和四肢；视频任务另检查首帧、运动与可播放性。
5. 文件位于已核实的数据目录，报告时不把浏览器画布持久化与磁盘生成结果混为一谈。

未经用户确认，不批量生成多个候选版本，不反复消耗显存和时间，也不将未通过验收的结果提升为新母图。
