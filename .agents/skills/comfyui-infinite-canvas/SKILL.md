# ComfyUI 无限画布操作规范

在当前可见画布内操作。不要另建隐形工作流、只写结果文件或打开空白项目来替代用户指定的画布。

## 必读资料

- 执行任何文件操作、交付结果或讨论保存／备份前，阅读 [storage.md](references/storage.md)。
- 调用画布、创建或连接节点前，阅读 [canvas-operations.md](references/canvas-operations.md)。
- 选择生图、局部修复、四视图、高清或视频流程时，阅读 [workflows.md](references/workflows.md)。
- 安装、更新或校验模型和节点时，先读仓库根目录 `AGENTS.md`；本 Skill 不替代安装规程。

## 固定操作顺序

1. 确认 `http://127.0.0.1:8790/` 已在支持 WebMCP 的浏览器中打开，调用 `canvas_get_state` 读取当前项目、节点、连线及状态。
2. 按标题、内容和现有连线复用正确节点。需要完整提示词时使用 `includePrompt: true`，不要靠截图猜测节点 ID。
3. 明确用户要求的输入、处理方式和验收目标；按 [workflows.md](references/workflows.md) 选择最少且合适的节点。
4. 创建或更新节点后，再次读取状态，核对返回的节点 ID、提示词、参数及连线。
5. 只对 `idle`、`done` 或已结束状态的节点提交一次生成。`uploading`、`queued`、`running`、`finishing` 状态只等待，不重复提交。
6. 等到真实终态并核验 `done` 及自动生成的结果节点；失败则保留准确错误，不反复刷任务。
7. 报告实际变更的节点、终态、结果节点及保存目录。区分“任务已提交”“生成成功”和“画布项目已保存”。

## 不可违反的边界

- 所有测试生成必须发生在当前画布并产生可见结果节点；不得只生成到磁盘。
- 不擅自删除用户节点、覆盖母图、取消他人任务、释放显存或重排整个画布。
- 不清理浏览器站点数据、localStorage 或 IndexedDB，不将生成目录当作画布项目备份。
- 不上传人物素材、生成结果、模型权重、Cookie、账号凭据到仓库或外部服务。
- 新节点不得遮挡或重叠现有节点。按“素材 → 处理 → 结果”组织，并保留可读标题。
- 只清理用户明确确认或本 Agent 新建且确认无用的临时节点；运行中删除节点可能取消任务。
- 如果接口返回 `ok: false`，停止该步骤并处理错误，不得将其描述为成功。
